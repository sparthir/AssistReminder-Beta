**AssistReminder - BETA**

This plugin is in development and is still buggy.

Fair Warning: If you don't like the use of coding AI's, then this isn't for you.  I'm not that familiar with Lua, and I've used a coding AI to try to help me write this plugin.

Currently, there is a production-stopping bug.  You can reproduce it as follows:
1. Set up a fellowship
2. Make sure there is no target assist set
3. Transfer the leadership to another player if that player is not already the leader
4. Get them to set an assist target
5. This should (most times) crash the game without error messages, straight to the Desktop

If you think you know why, please feel free to make a suggestion or add a pull request in.
